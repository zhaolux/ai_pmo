# AI PMO 项目管理套件

本仓库包含以能源行业合同全生命周期管理系统为案例的项目管理工作簿、参考输入、交付输出和 Python 自动化程序。

协作与操作边界见 [AGENTS.md](AGENTS.md)；当前进展、待办和待确认事项见 [ROADMAP.md](ROADMAP.md)。

## 目录

- `合同全生命周期管理系统-项目管理套件/`：正式项目管理套件；各管理领域按目录分开。
- `合同全生命周期管理系统-项目管理套件/automation/`：数据扫描、Agent 分析、周报及 POC 决策简报生成程序。
- `inputs/`：早期项目输入文件；正式套件中的 `inputs/` 为套件运行时使用的参考输入。
- `outputs/`：早期版本成果；正式套件中的 `outputs/` 为自动化运行结果。
- `docs/`：设计与计划文档。

数据来源、写入目标与重复运行风险见 [数据血缘与写入边界](合同全生命周期管理系统-项目管理套件/automation/docs/DATA_LINEAGE_AND_WRITE_POLICY.md)。

## 运行

新协作者请先从 [用户使用地图](合同全生命周期管理系统-项目管理套件/00_使用说明与配置/用户使用地图-20260924-V1.md) 入手：它按角色和场景说明"去哪个目录、跑哪条命令、守哪些红线"（同目录附单页信息图海报，可编辑、可导出 PNG）。

进入 `合同全生命周期管理系统-项目管理套件/automation/`，阅读其中的 `README.md`。常用命令：

```bash
./run.sh agents --date 2026-09-18
./run.sh weekly-report --date 2026-09-18
./run.sh decision-brief --date 2026-09-19
```

Agent 和报告默认只读源台账。项目基线、预算、风险等级、问题关闭和采购选型等事项必须由授权人确认。仓库不包含运行数据库、本机依赖、缓存和临时工作区。
