# 项目沟通管理计划

**项目**：能源行业合同全生命周期管理系统
**文档版本**：V1（2026-10-19）
**性质**：管理计划草案，供评审批准后生效；文中数据快照截至 2026-10-19
**配套台账**：《沟通会议与报告-20260918-V3.xlsx》（08 目录，沟通管理计划/会议计划/会议纪要/行动项台账/决策日志/报告台账/相关方沟通记录/升级事项）

## 1. 目的与范围

本计划定义项目沟通与会议体系：对谁、沟通什么、通过什么方式、什么频率、由谁负责、留下什么证据，以及沟通记录的闭环与升级规则。目标是让所有会议、决策、行动项和报告形成可追踪闭环——沟通总览表首行即写明此原则："会议、决策、行动项和报告必须形成可追踪闭环"。

沟通与相邻对象的边界：
- **沟通**（信息传递与协同）：本计划管辖
- **决策**（需拍板的事项）：决策日志，随 PMO 周报上报治理委员会
- **风险/问题升级**：升级事项 Sheet 与 06 目录风险问题流程衔接，本计划只规定沟通通道
- **报告产物**：周报/决策简报目录（08 目录），AI 驾驶舱（11 目录）为派生展示

## 2. 沟通设计原则

1. **按相关方设计，不用同一份报告覆盖所有人**（台账原文原则）：每条沟通线（CP-xxx）单独定义信息需求、目标、方式、频率和有效性验证标准。
2. **会议服务于决策、协同或验收**，没有议题和必须输出的会议不建议召开（会议计划表原则）。
3. **每条沟通线必须有输出/证据**：沟通不留痕视为未发生；有效性验证标准（CP 表第 L 列）是判断沟通失效的依据。
4. **频率与阶段匹配**：POC 期间每日站会、UAT 期间每日协调、上线前每日准备会，其余按周/双周/月度节奏。
5. **保密分级**：内部 / 内部敏感 / 商密三档，厂商相关沟通（CP-006）为商密，运维安全审计（CP-008）为敏感。

## 4. 会议体系

会议计划表（MTG-001～MTG-010）按治理→管理→执行→业务→技术→POC→迭代→质量→验收→上线十类覆盖全周期：

| 层级 | 会议 | 频率 | 必须输出 |
| --- | --- | --- | --- |
| 治理 | MTG-001 项目治理委员会 | 每月/触发 | 决策和授权记录 |
| 管理 | MTG-002 PMO周例会 | 每周一 | 周报、行动项、升级项 |
| 执行 | MTG-003 项目周例会 | 每周二 | 更新计划和行动项 |
| 业务 | MTG-004 需求专题会 | 每周二、四 | 需求结论、待决策项 |
| 技术 | MTG-005 架构与集成评审 | 双周/触发 | 评审结论、ADR、整改项 |
| POC | MTG-006 POC日站会 | 每工作日（2026-09-17 至 09-30） | POC每日状态和问题清单 |
| 迭代 | MTG-007 迭代计划/评审会 | 每 2 周迭代首尾日 | 迭代计划、评审结论 |
| 质量 | MTG-008 缺陷分级会 | 测试/UAT 期间每日 | 缺陷分级和修复承诺 |
| 验收 | MTG-009 UAT每日协调会 | 2027-04-16 至 05-10 | UAT日报、缺陷和决策 |
| 上线 | MTG-010 上线准备会 | 2027-05-11 至 05-31 | 上线准备结论、升级项 |

规则：
- **会议必须有必须输出**：纪要须在会后 1 个工作日内入《会议纪要》并关联会议 ID；无纪要的会议视为未召开。
- **行动项闭环**：会议产出的行动项进《行动项台账》（行动项ID），字段含责任人、截止日期、状态、时效判断（逾期自动标记）；"逾期行动项"由公式自动统计进沟通总览。
- **决策闭环**：会议形成的决策进《决策日志》（DEC- 前缀，如 DEC-001 CA产品POC选型），未决事项进待决策清单，超期未决自动升级为待升级事项。
- **近期关键节点**（沟通总览已排期）：POC 决策会 2026-09-30、项目启动准备会 2026-10-16、项目启动会 2026-10-20、需求基线评审 2026-11-30。

## 5. 沟通闭环与记录纪律

证据链固定为：**会议计划 → 会议纪要 → 行动项台账 → 决策日志 → 报告台账**，五个 Sheet 以会议 ID / 行动项 ID / 决策 ID 交叉引用（会议纪要 Sheet 自带决策ID、行动项ID、升级事项ID关联列），AI 巡检按此链路核对断点。

| Sheet | 用途 | 维护方 |
| --- | --- | --- |
| 沟通管理计划（CP 表） | 8 条沟通线的规则定义 | 项目经理，变更须评审 |
| 会议计划 | MTG- 会议排期与必须输出 | PMO |
| 会议纪要 | 会议结论与参会记录 | 主持人/记录人 |
| 行动项台账 | ACT- 行动项跟踪与逾期标记 | 行动责任人 |
| 决策日志 | D- 决策记录与待决策清单 | PMO |
| 报告台账 | 周报/月报/简报的发送与签收 | PMO |
| 相关方沟通记录 | 计划外沟通（邮件、电话、临谈）补录 | 各责任人 |
| 升级事项 | 超期未决与重大分歧的升级跟踪 | 项目集经理 |

纪律：
- 计划外沟通（非会议渠道的正式答复、厂商澄清、相关方口头承诺）须在《相关方沟通记录》补录，24 小时内完成。
- 沟通总览的统计数字（应开会议、待办/逾期行动项、待决策、待升级）全部为公式自动统计，不得手填。
- 行动项"完成"必须以交付证据为准，不以口头汇报为准。

## 6. 升级机制

- **沟通层面升级**：会议 2 次未达成共识、或行动项逾期超过 1 周、或决策超要求日期未拍板 → 填入《升级事项》，按 CP 表对应升级路径上报。
- **重大分歧**：业务与技术分歧由项目经理裁决；涉范围/预算/基线的分歧直接升级项目集经理；涉战略与投资的分歧升级治理委员会。
- **厂商沟通例外**：与 CA/电子文档/BI 厂商的分歧一律书面化（邮件/澄清函），口头结论无效，商密级材料不得出项目沟通群。

| 报告 | 频率 | 受众 | 产物位置 |
| --- | --- | --- | --- |
| PMO 周报 | 每周 | 项目管理团队、治理委员会 | 08/周报目录（AI 生成 + PMO 审核） |
| 管理月报 | 每月 | 治理委员会、赞助人 | 08/报告台账登记 |
| 决策简报 | 决策节点触发 | 治理委员会 | 08/决策简报目录 |
| 项目驾驶舱 | 每日 09:30 自动刷新 | 项目管理团队 | 11_AI_PMO中心（AI 派生展示） |

报告纪律：AI 生成的周报/简报为**待审材料**，PMO 核对事实后方可外发；驾驶舱为只读派生视图，不回写台账。

## 9. 台账结构与数据纪律

- 《沟通会议与报告-20260918-V3.xlsx》为单一事实源：11 个 Sheet（含《使用说明》与《_数据接口》）
- Agent 与自动化**只读**沟通台账；会议纪要内容、行动项关闭、决策确认、升级判定为人工事项
- 数据质量检查：每周扫描行动项逾期未更新、会议纪要缺关联 ID、决策超期未标记升级、计划外沟通未补录
- 与本计划的联动：本计划变更（新增 CP 线、调整会议频率）须同步更新 CP 表/会议计划 Sheet 并经评审

## 10. 审批

本计划经项目经理审核、项目集经理批准后生效；沟通矩阵、会议体系或升级机制变更须同步修订台账《沟通管理计划》《会议计划》Sheet 及使用说明。
